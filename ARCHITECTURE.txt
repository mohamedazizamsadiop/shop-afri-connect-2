FLUX DE DONNÉES - EXEMPLE COMPLET (Commande → Paiement → Retrait)
════════════════════════════════════════════════════════════════════════════════

1. CLIENT CRÉE UNE COMMANDE
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Frontend: POST /api/orders avec items[]                              │
   │ Backend: Crée Order avec status="created", génère paymentIntentId    │
   │ Response: {..., paymentIntentId, status: "created"}                  │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
2. CLIENT EFFECTUE LE PAIEMENT
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Frontend: Intégration Stripe (card, Elements)                        │
   │ Stripe: Traite le paiement                                           │
   │ Response: payment_intent.succeeded webhook                           │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
3. WEBHOOK STRIPE DÉCLENCHE
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Stripe → Backend: POST /api/stripe/webhook                           │
   │ • Marque Order.status = "paid"                                       │
   │ • Crée Ledger entries: split + commission pour chaque vendeur        │
   │ • Crée/met à jour Wallet.pendingBalance (+=produits montant)         │
   │ • Crée Notification "Commande confirmée"                             │
   │ • Envoie email client: "Commande confirmée"                          │
   │ • Envoie email vendeur: "Nouvelle commande"                          │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
4. VENDEUR TRAITE LA COMMANDE
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Vendeur: PUT /api/orders/:id/status → status="shipped"               │
   │ • Envoie email client: "Commande expédiée"                            │
   │ • Crée Notification                                                  │
   │                                                                      │
   │ Vendeur: PUT /api/orders/:id/status → status="delivered"             │
   │ • Envoie email client: "Commande livrée"                              │
   │ • Enregistre Order.deliveredAt = now()                               │
   │ • Crée Notification                                                  │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
5. AUTO-RELEASE APRÈS 7 JOURS (Cron ou manual call)
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Admin/Cron: POST /api/wallets/auto-release                           │
   │ • Trouve Orders: status="delivered" ET deliveredAt <= now()-7d       │
   │ • Pour chaque vendeur: Wallet.pendingBalance → availableBalance      │
   │ • Marque Order.released = true                                       │
   │ • Crée Ledger "release" entries                                      │
   │ • Crée Notifications pour vendeurs                                   │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
6. VENDEUR DEMANDE RETRAIT
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Vendeur: POST /api/withdrawals/request                               │
   │ • Vérifie Wallet.availableBalance >= montant                         │
   │ • Crée Withdrawal avec status="pending"                              │
   │ • Crée Notification vendeur                                          │
   └──────────────────────────────────────────────────────────────────────┘
                                    ▼
7. ADMIN APPROUVE LE RETRAIT
   ┌──────────────────────────────────────────────────────────────────────┐
   │ Admin: POST /api/withdrawals/:id/approve                             │
   │ • Marque Withdrawal.status = "approved"                              │
   │ • Déduit Wallet.availableBalance -= montant                          │
   │ • Crée Ledger "payout" entry                                         │
   │ • Envoie email vendeur: "Retrait approuvé"                           │
   │ • Crée Notification                                                  │
   │ • Déclenche paiement réel (externe)                                  │
   └──────────────────────────────────────────────────────────────────────┘

FIN: Cycle complet commande → paiement → retrait


SÉCURITÉ & PERMISSIONS
════════════════════════════════════════════════════════════════════════════════

Rôles:
  • ADMIN     - Gère plateforme, vendeurs, retraits
  • SELLER    - Vend produits, gère commandes, wallet
  • CLIENT    - Achète, passe commandes, profil

Contrôles d'accès:
  ✓ Produits: vendeur peut modifier/supprimer seulement ses produits
  ✓ Commandes: client voit seulement ses commandes
  ✓ Wallet: vendeur voit seulement son wallet
  ✓ Admin: endpoints protégés avec requireRole('admin')

JWT Tokens:
  ✓ Access token: 15 minutes (pour les opérations)
  ✓ Refresh token: 7 jours (stocké en DB pour logout)
  ✓ Révocation: possible via logout (supprimer token DB)

Webhooks Stripe:
  ✓ Signature verification: STRIPE_WEBHOOK_SECRET
  ✓ Idempotency: checksum paymentIntentId uniqueness
  ✓ Replay protection: timestamp validation
