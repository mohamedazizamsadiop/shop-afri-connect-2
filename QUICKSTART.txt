# QUICKSTART - MarketHub

Démarrage rapide du projet MarketHub en 5 minutes.

## 🚀 Option 1 : Développement Local

Recommandé pour développer sur le code.

### Terminal 1 - Frontend

```bash
npm install --legacy-peer-deps
npm start
```

Accès: http://localhost:8080

### Terminal 2 - Backend

```bash
cd server
npm install --legacy-peer-deps
npm run dev
```

Accès: http://localhost:4000

### Terminal 3 - Database (optionnel - local MongoDB)

```bash
mongod
```

---

## 🐳 Option 2 : Docker Compose

Recommandé pour la cohérence environnement local/production.

### Démarrer tout d'un coup

```bash
docker-compose up
```

Services disponibles:
- Frontend: http://localhost:8080
- Backend: http://localhost:4000
- MongoDB: localhost:27017

Pour arrêter:
```bash
docker-compose down
```

---

### Backend tests

## ⚙️ Configuration Initiale

### 1. Créer le fichier .env

```bash
cp server/.env.example server/.env
```

### 2. Éditer server/.env

Remplacer les valeurs:
```
MONGODB_URI=mongodb://localhost:27017/markethub
PORT=4000
JWT_SECRET=<générer avec: openssl rand -base64 32>
JWT_ACCESS_EXPIRES=15m
JWT_REFRESH_EXPIRES=7d
DEFAULT_COMMISSION_PERCENT=15
STRIPE_SECRET=sk_test_... (obtenir depuis Stripe)
STRIPE_WEBHOOK_SECRET=whsec_... (obtenir depuis Stripe)
```

Optionnel (pour emails):
```
MAIL_SERVICE=gmail
MAIL_USER=votre-email@gmail.com
MAIL_PASSWORD=app-password (générer depuis Google Account)
```

## ⚠️ Troubleshooting

### "Module not found"
```bash
npm install --legacy-peer-deps
cd server && npm install --legacy-peer-deps
```

### "Cannot connect to MongoDB"
```bash
# Si MongoDB local:
mongod

# Ou utiliser mongoDB externe:
# Éditer MONGODB_URI dans .env avec MongoDB Atlas URL
```

### "Port already in use"
```bash
# Trouver le processus:
lsof -i :4000  # pour backend
lsof -i :8080  # pour frontend

# Arrêter:
kill -9 <PID>

# Ou changer le PORT dans .env
```

### "Tests fail with MongoDB error"
```bash
# Utiliser MongoDB externe pour les tests:
TEST_MONGODB_URI=mongodb://localhost:27017/test npm test
```

### Frontend build errors
```bash
rm -rf node_modules dist
npm install --legacy-peer-deps
npm run build
```

## 🔄 Workflow Développement

1. **Démarrer l'application**
   ```bash
   docker-compose up  # Ou npm start/npm run dev séparément
   ```

2. **Consulter la documentation**
   - API: server/API_DOCS.md
   - Architecture: README.md
   - Implémentation: IMPLEMENTATION_SUMMARY.md

3. **Tester les endpoints**
   - Via Postman/Insomnia
   - Via curl
   - Via tests Jest

4. **Modifier le code**
   - Frontend: src/routes, src/components
   - Backend: server/src/routes, server/src/models

5. **Voir les changements**
   - Frontend: Recharge automatique (Vite)
   - Backend: Relance avec npm run dev (nodemon)

6. **Committer les changements**
   ```bash
   git add .
   git commit -m "feat: description"
   git push
   ```
