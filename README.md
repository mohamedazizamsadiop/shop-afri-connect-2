# MarketHub — Frontend (démo)

Démarrage rapide du frontend local (développement)

Prérequis
- Node.js 18+ recommandé

Installation

```bash
npm install --legacy-peer-deps
```

Lancer le serveur de développement

```bash
npm start
# puis ouvrir http://localhost:8080/
```

Notes
- Le projet utilise Vite + React + Tailwind (config fournie par @lovable.dev/vite-tanstack-config).
- Si `npm install` échoue sur des peerDeps, réexecuter avec `--legacy-peer-deps` comme ci‑dessus.
