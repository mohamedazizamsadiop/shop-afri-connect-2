# MarketHub — Backend (Express + MongoDB)

Démarrage rapide du backend local

Prérequis
- Node.js 18+
- MongoDB en local ou URI Atlas

Installation

```bash
cd server
npm install
cp .env.example .env
# modifier .env si besoin
npm run dev
```

L'API écoute par défaut sur le port défini dans `.env` (4000).
